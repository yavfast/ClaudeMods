## 05. Verification Criteria — модульні очікування

### 05_01. Functional Expectations  {#SP_CTX_05_01}

Тест рядка — той, чия назва починається з `<Contract> — <Scenario>` (без дужок наприкінці сценарію; назва може перелічувати сценарії через ` / `). Рядок, тест якого названо інакше, вказує його в кінці очікуваного результату: `[тест: «<початок назви>»; …]`; рядок без модульного тесту позначено `[live only: …]` (поведінку видно лише на живому хості) або `[not covered: …]` (аудит PL_AUD_CTX, CF-27).
